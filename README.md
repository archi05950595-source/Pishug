# 🐈 Пишуг — рыжий кот для Android

Пишуг — маленький интерактивный рыжий кот, который гуляет поверх других приложений на экране телефона, машет хвостом, подпрыгивает и мяукает.

## Возможности
- Кот самостоятельно гуляет по экрану и меняет направление.
- При касании подпрыгивает и мяукает (звук генерируется локально).
- Кота можно перетаскивать пальцем.
- Есть кнопки запуска и остановки.
- Не требует интернета, подписки и платных API.
- Для работы поверх других приложений нужно вручную разрешить отображение поверх других окон.

## Получить APK
Открой **Actions → Build Android APK** в репозитории GitHub, выбери успешный запуск и скачай артефакт **Pishug-APK**. Внутри ZIP будет файл **app-debug.apk**.

Если GitHub попросит включить Actions, включи их в настройках репозитория.

## Как пользоваться
1. Установи APK и открой «Пишуг».
2. Нажми «Разрешить поверх других окон» и включи соответствующее разрешение Android.
3. Вернись в приложение и нажми «Пустить Пишуга гулять».
4. Нажимай на кота, чтобы он мяукал; удерживай и двигай пальцем, чтобы перемещать его.
5. Остановить Пишуга можно в приложении или через действие уведомления «Убрать кота».

## Технологии
Java, Android SDK, Gradle, GitHub Actions. Рыжий кот рисуется средствами Android Canvas, без заимствованных изображений.

## Ограничения
Некоторые устройства Android энергосберегающими механизмами останавливают фоновые службы. Для непрерывной работы может потребоваться разрешить фоновую активность в настройках аккумулятора.

Пишуг — демонстрационная первая версия. Звук мяуканья синтезирован программно, не является записью настоящего кота.
